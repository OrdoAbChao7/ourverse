01 · PRIVACY

隐私边界

包内只包含当前导出者有权查看的内容。对方仅自己可见的记忆、附件与纪念日不会出现在这里，密封中的时间胶囊也不会被解开。

02 · INTEGRITY

完整性

每个文件都有 SHA-256 校验值。可在解压目录执行 sha256sum -c SHA256SUMS.txt，或运行项目中的 verify-export.mjs 校验整个包。

03 · PORTABILITY

可迁移

文字同时以 Markdown 保存，结构化数据保存在 memories.json 与 meta.json，媒体保留原始文件，不依赖本页面也能长期读取。

04 · BACKUP

长期保存

ZIP 默认不加密，请只放在信任的设备上。至少保留两份互相独立的备份，并定期重新校验哈希；单一硬盘或云盘不能作为唯一副本。

离线包不会主动联网，也不包含 API Key、会话令牌或上传签名链接。若在 file:// 下遇到音视频无法播放，可使用任意本地静态文件服务器打开本目录（仍然不需要联网），或换用 Chrome / Edge。
